One original fortune-cookie line for a software developer, entered in the
[make.fun competition](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).
`main.ts` writes the line to `/output/entry.txt`.

The line: "The legacy code you curse today was someone's proudest Friday
afternoon; be gentle, it outlived them all." — 105 characters, one sentence.
The code you curse was once someone's proudest work, and the twist is that
it outlived the people who wrote it.
